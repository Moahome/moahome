## 화면과 조회

경로는 `/manage/[propertyId]/accounting/income-statement`입니다. 공통 관리 레이아웃의 접근 확인, ListHeader·입력·달력·요약 카드·표를 사용합니다. 사용자 요청은 기간·동 조회, 수익·비용·순손익 요약, 계정과목별 표와 월별 그래프입니다. 후속 요청에 따라 표 위·그래프 아래의 전체 폭 배치를 사용하고 12개월 비교·전월 비교를 추가하지 않습니다.

필터는 `동 → 기간 → 조회` 순서입니다. 동을 먼저 선택하고 MonthRangePicker의 기간 선택창에서 `조회`를 누르면 확정한 시작·종료 월과 현재 선택한 동을 즉시 함께 적용합니다. 바깥 `조회` 버튼도 같은 처리를 사용합니다. 달력을 확정하기 전과 동만 선택한 단계에서는 결과·다운로드 범위를 유지합니다. 기본 조회는 서버의 한국 현재 월이며 주소의 startMonth/endMonth/building으로 복원합니다. Query key는 계정·관리대상·조회 범위를 포함합니다. 조회 중·실패·권한 없음·첫 부과 기준 없음·첫 부과 전 기간을 빈 손익과 구분하고 예시·이전 결과를 대신 표시하지 않습니다.

2026-11-05 동 선택 목록 보완: `조회 동` 필터와 동별 조회를 유지합니다. API의 과거 원천 대조용 삭제 동은 일반 선택지에서 제외해 삭제 후 같은 이름으로 재등록한 동이 중복 표시되지 않게 합니다. 삭제 동을 기존 주소에서 명시한 경우에만 해당 ID를 `동 이름 (삭제된 동)`으로 표시합니다. 이름으로 다른 동 ID를 합치거나 과거 귀속을 현재 동으로 바꾸지 않습니다.

첫 부과월을 자동 사용하고 별도 회계 시작 날짜 입력을 제공하지 않습니다. 기존 시작 설정자도 첫 부과월 기준으로 조회합니다. 기준이 없으면 부과 자료 없음으로 표시하며 MANAGER는 조회만 하고 분류 버튼을 숨깁니다. 미반영 자료가 남으면 `잠정 손익 · 확인 필요 N건`, 없으면 `등록·확인 자료 기준`으로 표시합니다. 마감·기초 잔액 대조 완료를 뜻하지 않습니다.

조회 실패는 공통 RequestError를 사용합니다. 통신·5xx와 잘못된 서버 응답(`INVALID_RESPONSE`)은 기존 서버 오류 이미지를 표시하며 재시도는 해당 조회만 다시 실행합니다. 권한·대상 없음은 기존 전용 이미지로 구분합니다. 추가 표시 필드가 없다는 이유만으로 이전 Server 응답을 조회 실패로 처리하지 않습니다.

- ADMIN의 `매칭` 버튼은 지출의 비용 과목만 선택합니다. 기존 지출 날짜를 사용하므로 별도 날짜·비용 귀속 월 달력과 변경 사유 입력을 표시하지 않습니다. 자동 매칭한 비용 과목은 미리 선택합니다. 일반관리비는 401 관리비수입에 자동 연결하므로 수익 성격을 다시 고르지 않습니다. 수동 확인이 남은 부과 항목도 예치·적립 선택 없이 연결할 401 관리비수입을 표시합니다. 같은 과목을 다시 매칭할 때 최신 revision을 전달하며 버전 번호를 업무 버튼명으로 노출하지 않습니다. 필드·달력·선택 입력과 저장·취소는 공통 UI를 사용합니다. 저장 실패 시 입력을 유지하고 성공 후 재조회합니다.
- 별도 귀속 이력이 없는 지출은 등록 날짜의 월에 자동 귀속합니다. 기존 명시적 귀속 이력은 보존합니다. 외부 부담은 `102 미수금`으로 분리하며 비용 계정 매칭은 우리 부담분에만 적용합니다. 일반관리비는 `401 관리비수입`으로 반영하고 같은 계정에 연결된 여러 부과 원본은 합계 한 행으로 표시합니다. 비용 선택지는 `801~810`, `812 보험료`, `813 잡비`을 코드 오름차순으로 표시하며 추가 과목도 코드 위치에 표시합니다. 표준 관리비의 부호 있는 조정은 같은 401에 반영합니다. 청구 전체가 음수인 환급·별도 예치·적립 등 미정 정책은 강제 일반 분류하지 않고 원천 확인으로 연결합니다. 화면에서 금액·배분 원본을 다시 입력하지 않습니다.

모바일 확인 목록은 `/income-statement/sources`, 분류는 `/income-statement/review?kind=expense|revenue&item=...`를 사용합니다. 제목은 공통 모바일 헤더에만 표시하며 본문에 제목이나 `손익계산서` 메뉴명을 반복하지 않습니다. 직접 접근·새로고침은 현재 관리대상 응답에서 원본 ID를 확인하고 공통 헤더 뒤로가기로 실제 이전 화면을 복원합니다. ## 그래프·금액·다운로드

2026-11-05 사용자 지정: 그래프의 비용 막대·범례와 PDF·PNG 비용 그래프는 `--chart-expense`의 `#F4A261`을 사용합니다. 음수의 Danger 표시 기준은 유지합니다.

월별·누계는 같은 자료를 사용하며 누계는 선택 기간의 시작 월부터 계산합니다. 기간 요약을 누계의 합으로 중복 계산하지 않습니다. 수익·비용은 막대, 순손익은 선이며 점을 호버·포커스·클릭·터치하면 점 옆의 흰색 말풍선에서 해당 월의 세 금액을 확인합니다. 아래 설명줄은 움직이지 않으며 Escape·바깥 선택·스크롤로 닫습니다.

금액 집계는 bigint 원 단위 정수이며 그래프 좌표만 비율로 변환합니다. 음수는 요약·말풍선·그래프의 음수 구간과 점·월별 내역에서 Danger로 표시하며 계정과목별 손익계산서 표와 해당 PDF·PNG에는 위 표의 사용자 지정 빨강을 사용합니다. 모바일은 표·그래프 내부만 가로 스크롤하며 페이지 전체는 넘치지 않습니다. 표 글씨를 작게 축소하지 않습니다.

[공통 다운로드](excelReports.md#공통-다운로드-화면과-모바일-진입-2026-11-02)의 Excel·PDF·이미지(PNG)와 실제 파일 미리보기를 사용합니다. PC 모달·모바일 `/income-statement/download` 경로를 유지합니다. 열 때의 적용 기간·동·월별/누계를 고정해 세 형식에 동일한 실제 자료·관리대상명·잠정 안내를 전달합니다. 직접 접근·새로고침으로 임시 자료가 없으면 공통 재선택 안내를 표시합니다.

Excel은 손익계산서·월별/누계 내역, 미반영 자료가 있으면 별도 확인 필요 시트를 제공합니다. PDF는 손익계산서·그래프/월별 내역과 필요 시 미반영 내역 페이지이며 PNG는 같은 PDF의 전체 페이지를 변환해 여러 장이면 ZIP으로 저장합니다. 미확인 원천 금액을 손익 합계에 합산하지 않습니다. 조회·다운로드는 마감 확정이 아닙니다.

후속 사용자 지정: PDF·PNG의 월별/누계 표는 헤더 `#DBEAFE`, 홀수 데이터 행 `#EAF3FF`, 짝수 데이터 행 `#E3EFFF`를 실제 셀 배경으로 채웁니다. 외곽·가로·세로 구분선은 `#BFD3EA`이며 음수는 Danger `#EF4444`, 0원 이상 순손익은 Primary `#2563EB`를 유지합니다. `--income-trend-table-*-background`와 기존 표 토큰을 공유합니다.

Excel의 손익계산서 시트와 다운로드 미리보기는 운영수익·운영비용·운영손익·영업외손익을 연블루 `#DBEAFE`와 굵은 글씨로, 일반 계정은 흰색으로, 최종 순손익은 `#BFDBFE`와 굵은 글씨로 구분합니다. 외곽·셀 경계는 `#BFD3EA`, 음수는 공통 Excel의 Danger를 사용합니다. 계정 순서·합계·숫자 정밀도는 유지하며 계층형 표 서식의 공통 연결은 [엑셀 문서](excelReports.md)를 참조합니다.

반영 내역에는 월말 미납 102·선입금 201을 자동 연결로 표시하되 손익 표·요약·그래프·파일의 records 합계에 더하지 않습니다. 지출 매칭의 계정과목에는 103을 제공하고 기존 상대 입금 후보를 선택합니다. 매칭 성공 시 양쪽을 손익에서 제외하고 원본 잔액·동 배분은 그대로 둡니다. 구 서버가 후보 필드를 제공하지 않으면 103 선택을 숨겨 저장 시차를 구분합니다.
