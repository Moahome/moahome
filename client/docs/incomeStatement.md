# 손익계산서

상태: **2026-11-04 실제 원천 조회 API·관리자 분류 저장 연결 구현**. 예시 자료는 테스트에만 둡니다. [공통 API](../../docs/api/incomeStatementApi.md), [업무 기준](../../docs/domain/domainRules.md#9-회계), [Server 처리](../../server/docs/incomeStatement.md)를 참조합니다. 정식 자동전표·계정별 원장·마감 구현과 구분합니다.

## 화면과 조회

경로는 `/manage/[propertyId]/accounting/income-statement`입니다. 공통 관리 레이아웃의 접근 확인, ListHeader·입력·달력·요약 카드·표를 사용합니다. 사용자 요청은 기간·동 조회, 수익·비용·순손익 요약, 계정과목별 표와 월별 그래프입니다. 후속 요청에 따라 표 위·그래프 아래의 전체 폭 배치를 사용하고 12개월 비교·전월 비교를 추가하지 않습니다.

MonthRangePicker의 시작·종료 월과 동은 `조회`로 함께 적용합니다. 적용 전 결과·다운로드 범위는 유지합니다. 기본 조회는 서버의 한국 현재 월이며 주소의 startMonth/endMonth/building으로 복원합니다. Query key는 계정·관리대상·조회 범위를 포함합니다. 조회 중·실패·권한 없음·시작 기준 미설정·시작 전 기간을 빈 손익과 구분하고 예시·이전 결과를 대신 표시하지 않습니다.

ADMIN은 시작 기준이 없을 때 회계 시작 월·회계연도 시작 월을 명시적으로 선택합니다. 저장된 기준은 직접 덮어쓰지 않는 현재 API 제약을 표시합니다. MANAGER는 조회만 하며 설정·분류 버튼을 숨깁니다. 미반영 자료가 남으면 `잠정 손익 · 확인 필요 N건`, 없으면 `등록·확인 자료 기준`으로 표시합니다. 마감·기초 잔액 대조 완료를 뜻하지 않습니다.

## 원천 확인과 목록

2026-11-04 후속 사용자 지적에 따라 아래 사항을 수정했습니다. 추가했던 `회계 확인 내역` 전체 표를 본문에 상시 표시하지 않습니다. 화면의 `확인 필요 N건`에서 미반영 자료를 확인하며 반영된 자료의 수정 접근은 `반영 내역`으로 제공합니다. 이는 미확인 금액을 드러내기 위한 현재 구현 방식이며 별도 회계 장부나 추가 사용자 요구로 기록하지 않습니다.

- 목록은 공통 DataTable·ListToolbar·Dropdown·Pagination을 사용하고 기본 10개, 10/20/50개 표시를 지원합니다. 확인 필요/전체 필터와 페이지 구분은 손익·다운로드 전체 합계를 바꾸지 않습니다.
- 행 선택으로 원래 업무를 확인하며 `원천` 링크·상세 버튼을 중복으로 나열하지 않습니다. 지출은 기존 BankingExpensePage, 수납은 MonthlyDetail, 입금은 PaymentDetail과 기타 입금 배분을 재사용합니다. **PC는 중앙 ClientModal, 모바일은 기존 독립 상세 경로**입니다. 여러 청구를 묶은 부과 항목은 부과 이력으로 이동합니다.
- 원천 종류와 식별자를 구분합니다. 입금을 출금용 transaction 상세로 보내지 않고 수납 ID의 receipts 경로를 사용합니다. 수납 연결 없는 원본은 거래 목록에서 확인합니다.
- 목록 열기·필터·페이지·표시 개수를 URL에 보존해 모바일 헤더·기기 뒤로가기로 원래 손익 조건과 목록 상태를 복원합니다. 일반 모달은 X·Escape·포커스 복귀를 공통 처리하고 원천 모달을 닫으면 목록에 남습니다. 원천에서 변경한 뒤 손익 자료를 다시 조회합니다.
- ADMIN의 짧은 `수정` 버튼은 지출의 비용 과목·귀속 월 또는 부과 항목의 수익 성격을 입력합니다. 같은 분류를 다시 확인할 때 변경 사유·최신 revision을 전달하며 버전 번호를 업무 버튼명으로 노출하지 않습니다. 필드·달력·선택 입력과 저장·취소는 공통 UI를 사용합니다. 저장 실패 시 입력을 유지하고 성공 후 재조회합니다.
- 귀속 월을 모르는 지출은 출금일을 비용월로 채우지 않습니다. 예치·적립, 음수·환불·외부 부담 등 확정되지 않은 정책은 강제 일반 분류 버튼을 제공하지 않고 원천 확인으로 연결합니다. 화면에서 금액·배분 원본을 다시 입력하지 않습니다.

## 그래프·금액·다운로드

월별·누계는 같은 자료를 사용하며 누계는 선택 기간의 시작 월부터 계산합니다. 기간 요약을 누계의 합으로 중복 계산하지 않습니다. 수익·비용은 막대, 순손익은 선이며 점을 호버·포커스·클릭·터치하면 점 옆의 흰색 말풍선에서 해당 월의 세 금액을 확인합니다. 아래 설명줄은 움직이지 않으며 Escape·바깥 선택·스크롤로 닫습니다.

금액 집계는 bigint 원 단위 정수이며 그래프 좌표만 비율로 변환합니다. 음수는 요약·표·말풍선·그래프의 음수 구간과 점·출력에서 Danger로 표시합니다. 모바일은 표·그래프 내부만 가로 스크롤하며 페이지 전체는 넘치지 않습니다. 표 글씨를 작게 축소하지 않습니다.

[공통 다운로드](excelReports.md#공통-다운로드-화면과-모바일-진입-2026-11-02)의 Excel·PDF·이미지(PNG)와 실제 파일 미리보기를 사용합니다. PC 모달·모바일 `/income-statement/download` 경로를 유지합니다. 열 때의 적용 기간·동·월별/누계를 고정해 세 형식에 동일한 실제 자료·관리대상명·잠정 안내를 전달합니다. 직접 접근·새로고침으로 임시 자료가 없으면 공통 재선택 안내를 표시합니다.

Excel은 손익계산서·월별/누계 내역, 미반영 자료가 있으면 별도 확인 필요 시트를 제공합니다. PDF는 손익계산서·그래프/월별 내역과 필요 시 미반영 내역 페이지이며 PNG는 같은 PDF의 전체 페이지를 변환해 여러 장이면 ZIP으로 저장합니다. 미확인 원천 금액을 손익 합계에 합산하지 않습니다. 조회·다운로드는 마감 확정이 아닙니다.
