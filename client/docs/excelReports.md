# 엑셀 다운로드 서식

2026-10-17 사용자가 제공한 `moahome_expense_template.xlsx`의 문서 디자인을 공통 기준으로 적용했습니다. 예시 거래·금액과 빈 템플릿 시트는 실제 다운로드 데이터로 복사하지 않습니다.

`shared/lib/excel-report`는 맑은 고딕, 큰 제목·설명, 조회 조건·건수·주요 합계 요약, 옅은 파란 헤더, 흰색·옅은 배경 교차 행, 합계 행을 구성합니다. 제목은 24pt·56 높이, 표는 14pt·42 높이, 합계는 16pt·48 높이를 사용합니다. 표 헤더까지 고정하고 기본 격자선은 숨깁니다. 6열 이상의 보고서는 가로 인쇄 방향을 사용합니다.

지출·월별 수납·주민 목록·동별 잔고 보고서는 각 화면에서 조회한 전체 결과를 전달합니다. 표시 개수·페이지가 다운로드 대상을 줄이지 않습니다. 수납 보고서의 청구 충당액과 실제 입금액은 구분합니다. 지출 보고서는 관리 동의 실제 부담액을 사용하며 외부 부담액을 합산하지 않습니다. 주민 목록은 기존 허용 세 열과 전체 연락처 범위를 유지합니다.

원화는 15자리 이내에서 숫자 셀과 천 단위·원 표시 서식을 사용합니다. Excel의 15자리 표현 한도를 넘는 합계는 정확한 정수 문자열로 저장합니다. 이름·전화번호·동호수·메모는 문자열 셀로 저장하며 수식으로 만들지 않습니다. 합계는 다운로드 시 계산한 값이며 파일 수정에 따라 재계산되는 수식은 넣지 않습니다.

재업로드하는 주민 등록·기존 잔액 인계 양식은 첫 시트의 기존 헤더와 입력 행 위치를 유지합니다. 작성 안내는 별도 시트를 사용하며 보고서 제목·합계 행을 입력 데이터 중간에 끼워 넣지 않습니다. 주민 등록 정적 양식도 같은 옅은 파란 헤더와 교차 행을 사용합니다. 스타일을 지원하지 않는 기존 결과 CSV는 형식·마스킹·수식 방지 규칙을 유지합니다.

월별 정산과 잔고·정산의 다운로드는 각각 **한 시트**를 사용합니다. [월별 정산](monthlySettlement.md#excelpdf-자료-범위)은 새 첨부 템플릿의 종합 요약·점검·통장 잔액·동별 보유금·수납·입출금·외부 부담금을 `월별 정산 보고서` 시트에 배치합니다. [잔고·정산](bankingManagement.md#동별-입출금-명세-다운로드)은 기존 동별 입금·배분 지출·거래 후 잔액과 기초/월말 잔액·소계·합계를 `동별 입출금 내역` 시트로 제공합니다. 두 서식은 `createReportCell`의 정확한 정수·문자열 보호를 재사용하고 다른 보고서 서식은 유지합니다. 각 모달의 미리보기·PDF·이미지와 내려받는 Excel의 자료 범위는 같습니다.

월별 수납은 기존 한 시트·필터 전체·정수 정밀도 규칙을 유지하면서 PDF·이미지와 같은 문서 자료를 사용합니다. 빌라 이름·조회 조건·미리보기와 가로 PDF 구성은 [월별 수납 보고서](paymentManagement.md#월별-수납-보고서-미리보기다운로드-2026-10-31)를 참조합니다.

월별 수납의 전용 서식은 후속 사용자 시안에 따라 26pt 제목·20pt 조회 월·의미 색상의 금액 카드·14pt 표를 사용합니다. 공통 셀의 정수 정밀도·문자열 보호는 재사용하고 다른 보고서의 기본 서식은 유지합니다.

PDF 미리보기와 PNG 변환은 PDF.js의 `legacy` 빌드와 같은 버전의 `legacy` Worker를 함께 사용합니다. 최신 Map API가 없는 앱 실행 환경에서도 페이지를 그릴 수 있도록 PDF.js가 제공하는 호환 처리를 적용합니다. 해당 API가 없는 문서·Worker 환경의 미리보기와 실제 PDF·PNG 다운로드는 공통 보고서 회귀 검사에서 확인합니다.

## 공통 다운로드 화면과 모바일 진입 (2026-11-02)

사용자 요청: 다운로드의 외곽·상태 안내를 공통화하고, PC는 모달·모바일은 독립 페이지로 표시합니다. 좁은 모바일 모달에서 형식 이름·설명이 잘게 줄바꿈되는 문제와 오류 그림 누락을 수정합니다.

- `DownloadLayout`이 제목·설명·본문·푸터·닫기와 modal/page 표시를 담당합니다. `ReportDownload`는 보고서 문서·지원 형식·필터·파일 생성 함수를 props로 받아 같은 자료를 미리보고 저장합니다. 업무 자료 계산은 기존 화면의 모델을 유지합니다.
- 후속 사용자 정정에 따라 다운로드의 본문 배경도 헤더·푸터와 같은 흰색 Card 토큰을 사용합니다. 오류 그림 주변에 별도의 회색 배경을 넣지 않습니다.
- 월별 수납·동별 입출금·월별 정산은 기존 Excel·PDF·PNG를 유지합니다. 지출 내역은 기존 Excel만 지원하며 같은 미리보기 틀을 사용합니다. 주민 목록은 같은 외곽을 사용하되 별도 인증 조회·번호 마스킹·처음 5명 미리보기·전체 범위 Excel 저장을 유지합니다. 주민용 PDF·PNG는 추가하지 않습니다.
- 모바일 보고서 경로는 기존 목록 아래 `/download`입니다. `/banking/monthly/download`, `/payments/monthly/download`, `/banking/balances/download`, `/banking/expenses/download`, `/closing/monthly/download`에서 공통 화면을 표시하며 주민은 기존 `/residents/export`를 유지합니다. 공통 헤더의 뒤로가기와 기기 뒤로가기로 실제 이전 화면·조건에 복귀하고 본문·푸터의 목록·취소·닫기 버튼은 표시하지 않습니다.
- `ReportDownloadProvider`는 현재 계정·관리대상에 한정한 임시 화면 자료만 메모리로 연결합니다. 보고서·연락처·전체 선택 자료를 URL·브라우저 저장소에 쓰지 않습니다. 새로고침·직접 접근·뒤로가기 후 앞으로 가기에서 자료가 없으면 재선택 안내를 표시하며 전체 출력으로 바꾸지 않습니다. 모달과 페이지는 관리 레이아웃의 접근 권한 확인 안에서만 표시합니다.
- 생성 대기는 공통 `LoadingState`, 생성·그리기 실패는 기존 `StateMessage`의 확인 필요 그림과 해당 단계의 재시도 버튼으로 표시합니다. 로컬 파일 생성 실패를 서버 연결 장애로 단정하지 않습니다. PDF 페이지가 한 장이어도 같은 페이지를 다시 그릴 수 있으며 미리보기 아래 페이지 이동은 유지합니다. A4 가로·세로 표시는 실제 보고서 방향에 맞춥니다.

통장 관리의 일반 새로고침 영역 제거 기준은 [통장 관리 화면](bankingManagement.md#통장-관리-새로고침-영역-제거-2026-11-02)을 따릅니다.
