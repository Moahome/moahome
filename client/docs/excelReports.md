# 엑셀 다운로드 서식

2026-10-17 사용자가 제공한 `moahome_expense_template.xlsx`의 문서 디자인을 공통 기준으로 적용했습니다. 예시 거래·금액과 빈 템플릿 시트는 실제 다운로드 데이터로 복사하지 않습니다.

`shared/lib/excel-report`는 맑은 고딕, 큰 제목·설명, 조회 조건·건수·주요 합계 요약, 옅은 파란 헤더, 흰색·옅은 배경 교차 행, 합계 행을 구성합니다. 제목은 24pt·56 높이, 표는 14pt·42 높이, 합계는 16pt·48 높이를 사용합니다. 표 헤더까지 고정하고 기본 격자선은 숨깁니다. 6열 이상의 보고서는 가로 인쇄 방향을 사용합니다.

지출·월별 수납·주민 목록·동별 잔고 보고서는 각 화면에서 조회한 전체 결과를 전달합니다. 표시 개수·페이지가 다운로드 대상을 줄이지 않습니다. 수납 보고서의 청구 충당액과 실제 입금액은 구분합니다. 지출 보고서는 관리 동의 실제 부담액을 사용하며 외부 부담액을 합산하지 않습니다. 주민 목록은 기존 허용 세 열과 전체 연락처 범위를 유지합니다.

원화는 15자리 이내에서 숫자 셀과 천 단위·원 표시 서식을 사용합니다. Excel의 15자리 표현 한도를 넘는 합계는 정확한 정수 문자열로 저장합니다. 이름·전화번호·동호수·메모는 문자열 셀로 저장하며 수식으로 만들지 않습니다. 합계는 다운로드 시 계산한 값이며 파일 수정에 따라 재계산되는 수식은 넣지 않습니다.

재업로드하는 주민 등록·기존 잔액 인계 양식은 첫 시트의 기존 헤더와 입력 행 위치를 유지합니다. 작성 안내는 별도 시트를 사용하며 보고서 제목·합계 행을 입력 데이터 중간에 끼워 넣지 않습니다. 주민 등록 정적 양식도 같은 옅은 파란 헤더와 교차 행을 사용합니다. 스타일을 지원하지 않는 기존 결과 CSV는 형식·마스킹·수식 방지 규칙을 유지합니다.

월별 정산 다운로드는 사용자 후속 정정에 따라 동별 입금·지출 내역을 **한 시트**로 제공합니다. 동별 현금 원장을 사용한 거래일시·통장·구분·입금자/지출명·입금액·지출액·누적 잔액과 동별 기초·월말 잔액·소계·전체 합계를 넣습니다. 후속 첨부 엑셀의 진한 제목 띠·가로 요약 카드·동별 자금 요약·동별 명세 서식을 적용하고 날짜는 월초에서 월말 순으로 표시합니다. 이 화면의 서식은 공통 createReportCell의 정밀도·문자열 보호를 재사용해 조합하며 다른 보고서 서식은 유지합니다. 대시보드의 각 표를 시트로 분리하지 않으며 PDF도 같은 입출금 문서를 사용합니다. 다운로드 모달의 전체/개별 동·계좌 선택을 함께 적용하고 미리보기·파일·합계를 같은 범위로 제한합니다. 자세한 흐름은 [월별 정산](monthlySettlement.md#다운로드-모달과-미리보기)을 따릅니다.
